## Вопросы, которые нужно уметь объяснить

**Почему два источника?** API содержит экономический и демографический показатели;
HTML-таблица ООН даёт географический контекст, используемый в группировке и графиках.

**Почему 2023?** Это заранее выбранный общий год. Не смешиваем последние доступные
значения разных лет и не утверждаем, что 2023 — самый свежий год.

**Что делает requests?** Отправляет HTTP GET. `raise_for_status()` сообщает об ошибках HTTP,
`timeout=60` ограничивает ожидание. HTTPAdapter повторяет некоторые временные ошибки.

**Что делает BeautifulSoup?** Разбирает сохранённый HTML: находит table с id downloadTableEN,
затем строки tr и ячейки td/th. API для UN-таблицы и pandas.read_html не используются.

**Что означает пагинация?** API может разбить ответ на страницы. Цикл читает поле pages
и запрашивает следующую страницу, пока не собраны все записи. В этой загрузке страницы
проверяются по метаданным; 400 — размер страницы, а не требуемый размер выборки.

**Зачем ISO3?** Названия могут различаться между источниками. Трёхбуквенный код устойчивее.
`validate='one_to_one'` предотвращает случайное размножение строк при неуникальном ключе.

**Как удалены агрегаты?** По `region.id == 'NA'` в метаданных World Bank. Например, мировой
показатель нельзя считать отдельной страной. Агрегаты не определяются на глаз по названию.

**Как обработаны пропуски?** После объединения исключены 15 уникальных
строк из 217. Причины могут пересекаться, поэтому нельзя просто складывать
число пропусков по столбцам. Все исключения сохранены.

**Почему нет искусственно добавленных дубликатов?** Проверка показала реальные количества:
0 для API и 0 для UN. Нулевой результат тоже результат.

**Зачем логарифм?** GDP сильно различается по масштабу. Переход от $1,000 к $10,000 и от
$10,000 к $100,000 означает одинаковое изменение log10 на единицу. Логарифм определён для
положительных чисел; неположительные GDP проверяются до преобразования.

**Pearson и Spearman?** Pearson измеряет линейную связь. Spearman — связь рангов; в коде
это `.rank().corr(...)`. Ни один коэффициент не доказывает причинность.

**Что показывает boxplot?** Центральная линия — медиана, коробка — от 25-го до 75-го
процентиля, усы обычно до 1.5 межквартильного размаха. Точки за усами не обязательно ошибки.

**Какие даты стоят в работе?** Наблюдения: 2023. Сбор: 12.10.2026. Дата обновления API
показана отдельно. Дедлайны из задания не выдаются за дату фактического выполнения.

**Как проверена воспроизводимость?** Сохранены исходные ответы и SHA-256 хеши.
Notebook повторно выполняется с `USE_SAVED_SNAPSHOT=True`; итоговая таблица и metrics.json
сравниваются с сохранённым результатом первого полного запуска на реально загруженных данных.
