## Reproduce

Use Python 3.12. Open a terminal in this folder:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Open the notebook and set `USE_SAVED_SNAPSHOT = True` in its first code cell.
Run all cells. This mode needs no network and verifies the raw-file hashes.
For new collection, set the flag to `False`; this overwrites the local snapshot and
may produce revised statistics. Use a fresh copy when refreshing. The included PDF
describes the saved snapshot and is not automatically regenerated by the notebook.

## Results from the included snapshot

- Complete sample: 202 countries/areas in 2023.
- Pearson GDP-life correlation: 0.620.
- Pearson log10(GDP)-life correlation: 0.856.
- Spearman correlation: 0.866.
- Median life expectancy: 74.5 years.
- 15 of 217 country/area rows excluded.

Countries and areas have equal weight. Association is not causation. GDP is in current
US dollars, not PPP. The UN classification is current at collection time.
